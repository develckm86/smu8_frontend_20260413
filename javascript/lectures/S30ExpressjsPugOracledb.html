Lesson 1

템플릿 엔진이란?

템플릿 엔진은 서버에서 HTML을 만들 때, 미리 작성한 템플릿 파일의 변수 자리에 실제 데이터를 넣어 최종 HTML로 변환하는 도구입니다.

핵심 문장: 데이터베이스가 “데이터를 가져오는 역할”이라면, 템플릿 엔진은 “가져온 데이터를 화면으로 보여주는 역할”입니다.

정적 HTML과 동적 HTML

구분설명예시
정적 HTML내용이 항상 같은 HTML회사 소개, 고정 안내문
동적 HTML데이터에 따라 내용이 바뀌는 HTML부서 목록, 게시글 목록, 로그인 사용자 정보

템플릿 엔진을 사용하지 않는 경우

HTML을 문자열로 직접 만들어야 하므로 코드가 길어지고 관리하기 어렵습니다.

템플릿 엔진 없이 HTML 문자열로 응답
res.send(`
  <html>
    <body>
      <h1>부서 목록</h1>
      <table>
        <tr>
          <td>10</td>
          <td>ACCOUNTING</td>
          <td>NEW YORK</td>
        </tr>
      </table>
    </body>
  </html>
`);

템플릿 엔진을 사용하는 경우

HTML 구조는 Pug 파일에 작성하고, Express에서는 데이터만 넘깁니다.

Express에서 Pug 파일 렌더링
res.render('dept', {
  title: 'DEPT 부서 목록',
  deptList: result.rows
});
Express 데이터 → Pug 템플릿 → HTML 생성 → 브라우저 출력

템플릿 엔진의 주요 기능

변수 출력

서버가 전달한 값을 HTML에 표시합니다.

반복문

배열 데이터를 여러 줄의 HTML로 출력합니다.

조건문

상황에 따라 다른 HTML을 출력합니다.

화면 분리

라우터 코드와 화면 코드를 분리해서 유지보수를 쉽게 합니다.

Lesson 3

Oracle DB와 oracledb

oracledb는 Node.js 애플리케이션에서 Oracle Database에 접속하기 위해 사용하는 Oracle 공식 드라이버입니다.

oracledb의 역할

Node.js 쪽 역할

Express 라우터에서 DB 접속 요청을 만들고 SQL을 실행합니다.

Oracle DB 쪽 역할

SQL을 실행하고 조회 결과를 Node.js로 반환합니다.

Node.js → oracledb 드라이버 → Oracle Database → 조회 결과 rows

기본 용어

용어설명
DriverNode.js와 Oracle DB가 서로 통신할 수 있게 해 주는 모듈입니다.
ConnectionNode.js와 DB 사이에 열린 연결 통로입니다.
Pool여러 DB 연결을 미리 만들어 두고 재사용하는 저장소입니다.
execute()SQL 또는 PL/SQL을 실행하는 함수입니다.
rowsSELECT 실행 결과 행 목록입니다.

설치와 불러오기

설치
npm install oracledb
모듈 불러오기
const oracledb = require('oracledb');

Thin 모드와 Thick 모드

구분설명수업 기준
Thin 모드별도 Oracle Client 설치 없이 JavaScript 기반으로 접속합니다.일반 실습에서는 Thin 모드 기준으로 진행합니다.
Thick 모드Oracle Client 라이브러리를 사용합니다.특정 고급 기능이나 환경에서 필요할 수 있습니다.

DB 접속 정보

Oracle XE 접속 설정

  user: 'scott',
  password: 'tiger',
  connectString: 'localhost:1521/XEPDB1'

주의: 사용자가 처음 적은 localhst:1521/XEPDB1는 오타입니다. 반드시 localhost:1521/XEPDB1로 작성합니다.

OUT_FORMAT_OBJECT

조회 결과를 객체 형태로 받기 위해 다음 설정을 사용합니다.

조회 결과 객체화
oracledb.outFormat = oracledb.OUT_FORMAT_OBJECT;
설정하지 않은 경우 예시설정한 경우 예시
[10, 'ACCOUNTING', 'NEW YORK'] { deptno: 10, dname: 'ACCOUNTING', loc: 'NEW YORK' }

Pug에서 dept.deptno, dept.dname, dept.loc처럼 사용하기 위해 객체 형태가 수업에 더 적합합니다.

Lesson 4

단일 커넥션으로 DEPT 조회

커넥션 풀을 배우기 전에, 먼저 단일 연결로 Oracle DB에 접속하고 DEPT 테이블을 조회합니다.

SQL 확인

Oracle SQL Developer 또는 SQL*Plus에서 먼저 확인
SELECT deptno, dname, loc
FROM dept
ORDER BY deptno;

단일 커넥션 예제

test-dept.js
const oracledb = require('oracledb');

// SELECT 결과를 배열이 아니라 객체 형태로 받기
oracledb.outFormat = oracledb.OUT_FORMAT_OBJECT;

const dbConfig = {
  user: 'scott',
  password: 'tiger',
  connectString: 'localhost:1521/XEPDB1'
};

async function testDept() {
  let connection;

  try {
    // Oracle DB 접속
    connection = await oracledb.getConnection(dbConfig);

    // SQL 실행
    const result = await connection.execute(`
      SELECT
        deptno AS "deptno",
        dname  AS "dname",
        loc    AS "loc"
      FROM dept
      ORDER BY deptno
    `);

    console.log(result.rows);
  } catch (err) {
    console.error('DB 오류:', err);
  } finally {
    // 사용한 DB 연결 닫기
    if (connection) {
      try {
        await connection.close();
      } catch (err) {
        console.error('연결 종료 오류:', err);
      }
    }
  }
}

testDept();

Lesson 5

커넥션 풀 구현

커넥션 풀은 DB 연결을 미리 만들어 두고, 요청이 들어올 때 연결을 빌려 쓴 뒤 다시 반납하는 방식입니다.

단일 커넥션 방식

요청→ DB 연결 생성→ SQL 실행→ DB 연결 종료

커넥션 풀 방식

서버 시작→ 풀 생성→ 요청마다 연결 대여→ SQL 실행→ 연결 반납

커넥션 풀 설정값

옵션예시설명
poolMin1최소 유지 연결 수
poolMax5최대 연결 수
poolIncrement1연결이 부족할 때 증가 단위
poolTimeout60사용하지 않는 연결 정리 시간
queueTimeout60000연결이 없을 때 대기 가능한 시간
중요: connection.close()는 풀 전체를 닫는 것이 아니라, 빌린 연결을 풀에 반납하는 의미입니다. 풀 전체 종료는 pool.close()로 처리합니다.

db.js

db.js
const oracledb = require('oracledb');

// SELECT 결과를 객체 형태로 받기
oracledb.outFormat = oracledb.OUT_FORMAT_OBJECT;

let pool;

// 서버 시작 시 한 번만 실행: 커넥션 풀 생성
async function initPool() {
  pool = await oracledb.createPool({
    user: 'scott',
    password: 'tiger',
    connectString: 'localhost:1521/XEPDB1',

    // 커넥션 풀 설정
    poolMin: 1,
    poolMax: 5,
    poolIncrement: 1,
    poolTimeout: 60,
    queueTimeout: 60000
  });

  console.log('Oracle connection pool created');
}

// 요청 처리 중 필요할 때 풀에서 연결 하나 빌리기
async function getConnection() {
  if (!pool) {
    throw new Error('Connection pool has not been initialized.');
  }

  return await pool.getConnection();
}

// 서버 종료 시 커넥션 풀 전체 정리
async function closePool() {
  if (pool) {
    await pool.close(10);
    console.log('Oracle connection pool closed');
  }
}

module.exports = {
  initPool,
  getConnection,
  closePool
};

app.js

app.js
const express = require('express');
const path = require('path');
const db = require('./db');

const app = express();
const PORT = 3000;

app.set('views', path.join(__dirname, 'views'));
app.set('view engine', 'pug');

app.get('/', (req, res) => {
  res.redirect('/dept');
});

// 1) DB 조회 결과를 JSON으로 확인하는 라우터
app.get('/dept-json', async (req, res) => {
  let connection;

  try {
    connection = await db.getConnection();

    const result = await connection.execute(`
      SELECT
        deptno AS "deptno",
        dname  AS "dname",
        loc    AS "loc"
      FROM dept
      ORDER BY deptno
    `);

    res.json(result.rows);
  } catch (err) {
    console.error(err);
    res.status(500).json({
      error: 'DB 조회 오류',
      message: err.message
    });
  } finally {
    if (connection) {
      try {
        // 풀을 닫는 것이 아니라, 빌린 연결을 풀에 반납한다.
        await connection.close();
      } catch (err) {
        console.error('연결 반납 오류:', err);
      }
    }
  }
});

// 2) DB 조회 결과를 Pug 화면으로 출력하는 라우터
app.get('/dept', async (req, res) => {
  let connection;

  try {
    connection = await db.getConnection();

    const result = await connection.execute(`
      SELECT
        deptno AS "deptno",
        dname  AS "dname",
        loc    AS "loc"
      FROM dept
      ORDER BY deptno
    `);

    res.render('dept', {
      title: 'DEPT 부서 목록',
      deptList: result.rows
    });
  } catch (err) {
    console.error(err);
    res.status(500).send(`
      <h1>DB 조회 오류</h1>
      <pre>${err.message}</pre>
    `);
  } finally {
    if (connection) {
      try {
        await connection.close();
      } catch (err) {
        console.error('연결 반납 오류:', err);
      }
    }
  }
});

// 서버 시작 순서: DB 풀 생성 → Express 서버 시작
async function startServer() {
  try {
    await db.initPool();

    app.listen(PORT, () => {
      console.log(`Server running: http://localhost:${PORT}`);
    });
  } catch (err) {
    console.error('Server startup failed:', err);
  }
}

startServer();

// Ctrl + C로 서버 종료 시 커넥션 풀 정리
process.on('SIGINT', async () => {
  console.log('\nServer is shutting down...');

  try {
    await db.closePool();
    process.exit(0);
  } catch (err) {
    console.error(err);
    process.exit(1);
  }
});

최종 실행 흐름

  2. db.initPool()이 Oracle 커넥션 풀 생성
  3. Express 서버가 3000번 포트에서 실행
  4. 브라우저가 /dept 요청
  5. 라우터가 db.getConnection()으로 연결 대여
  6. SELECT deptno, dname, loc FROM dept 실행
  7. 조회 결과를 deptList로 Pug에 전달
  8. Pug가 HTML 테이블 생성
  9. connection.close()로 연결 반납

Lesson 8

실습 과제와 점검표

실습 과제

  1. /dept-json에 접속해서 JSON 결과가 출력되는지 확인합니다.
  2. /dept에 접속해서 Pug 테이블이 출력되는지 확인합니다.
  3. Pug 화면에 “총 부서 수”를 추가합니다.
  4. SQL 정렬 기준을 loc로 바꿔 봅니다.
  5. DEPT 테이블에 새 부서를 추가한 뒤 화면에 반영되는지 확인합니다.

점검표

  • Express에서 app.set('view engine', 'pug')를 설명할 수 있다.
  • res.render()가 하는 일을 설명할 수 있다.
  • Pug의 each 반복문으로 배열을 출력할 수 있다.
  • oracledb가 Oracle DB 드라이버라는 것을 설명할 수 있다.
  • connection.execute()로 SELECT를 실행할 수 있다.
  • oracledb.OUT_FORMAT_OBJECT를 사용하는 이유를 설명할 수 있다.
  • 커넥션 풀의 createPool(), getConnection(), close()를 구분할 수 있다.
  • DB 조회 결과를 Pug 화면에 출력할 수 있다.

한 줄 요약

Express는 요청을 받고, oracledb는 Oracle DB에서 DEPT 데이터를 조회하고, Pug는 조회 결과를 HTML 화면으로 출력합니다. 커넥션 풀은 DB 연결을 미리 만들어 두고 재사용하여 웹 애플리케이션의 안정성과 성능을 높입니다.
