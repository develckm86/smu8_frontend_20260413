1. jQuery란?

jQuery는 JavaScript를 더 짧고 간단하게 작성할 수 있도록 도와주는 JavaScript 라이브러리이다. HTML 요소 선택, DOM 조작, 이벤트 처리, 애니메이션, Ajax 작업을 간단한 문법으로 처리할 수 있도록 만들어졌다.

JavaScript만 사용하면 다음과 같이 작성해야 하는 코드를,

document.querySelector("#title").textContent = "안녕하세요";

jQuery를 사용하면 다음과 같이 줄여 쓸 수 있다.

$("#title").text("안녕하세요");

jQuery는 오래된 웹 프로젝트, 관리자 페이지, 간단한 프론트엔드 기능 구현, 기존 유지보수 프로젝트에서 많이 사용된다. 최신 웹 개발에서는 React, Vue, Svelte 같은 프레임워크나 순수 JavaScript의 기능도 많이 사용되므로, jQuery는 기존 코드 이해와 빠른 DOM 조작을 위한 도구로 이해하는 것이 좋다.

jQuery의 핵심은 “HTML 요소를 쉽게 선택하고, 쉽게 바꾸고, 쉽게 이벤트를 연결하는 것”이다.

2. jQuery를 모듈로 사용하는 방법

jQuery는 CDN으로 불러와 전역 변수처럼 사용할 수도 있고, npm으로 설치한 뒤 모듈 방식으로 사용할 수도 있다. 모듈 방식은 Vite, Webpack, Parcel 같은 번들러를 사용하는 프로젝트에서 적합하다.

2.1. 모듈 방식의 기본 흐름

모듈 방식에서는 HTML 파일에서 jQuery CDN을 직접 불러오지 않는다. 대신 npm으로 jQuery를 설치하고, JavaScript 파일에서 import 문으로 jQuery를 가져온다.

구분 CDN 방식 모듈 방식
불러오는 위치 HTML의 script 태그 JavaScript 파일의 import 문
설치 여부 별도 설치 없이 CDN 주소 사용 npm install jquery 필요
주요 사용 환경 간단한 HTML 예제, 정적 페이지 Vite, Webpack 같은 빌드 도구 기반 프로젝트

2.2. Vite 프로젝트에서 jQuery 사용하기

Vite 프로젝트를 만든 뒤 jQuery를 설치한다.

npm create vite@latest jquery-module-demo
cd jquery-module-demo
npm install
npm install jquery

HTML 파일에서는 모듈 JavaScript 파일을 연결한다.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>jQuery 모듈 사용</title>
</head>
<body>
  <h1 id="title">jQuery 모듈 예제</h1>
  <button id="btn">변경</button>

  <script type="module" src="/src/main.js"></script>
</body>
</html>

src/main.js 파일에서 jQuery를 가져와 사용한다.

import $ from "jquery";

$("#btn").on("click", function() {
  $("#title").text("jQuery를 모듈로 불러왔습니다.");
});

개발 서버를 실행한다.

npm run dev

브라우저에서 버튼을 클릭하면 제목이 변경된다. 이 방식에서는 jQuery가 전역으로 자동 등록되는 것이 아니라, import $ from "jquery"로 가져온 파일 안에서 사용된다.

2.3. 전역 변수로 등록해야 하는 경우

일부 오래된 플러그인이나 기존 코드는 window.$ 또는 window.jQuery가 있어야 동작한다. 이런 경우에는 jQuery를 import한 뒤 전역 객체에 등록할 수 있다.

import $ from "jquery";

window.$ = $;
window.jQuery = $;

$("#title").text("전역 jQuery 등록 완료");
모듈 방식에서는 필요한 파일에서 jQuery를 직접 import하는 것이 기본이다. 기존 플러그인 호환이 필요할 때만 window.$, window.jQuery에 등록한다.

2.4. 브라우저에서 import만 바로 사용하면 안 되는 경우

HTML에서 다음과 같이 작성하는 방식은 일반적인 브라우저 환경에서 바로 동작하지 않을 수 있다.

<script type="module">
  import $ from "jquery";
</script>

브라우저는 기본적으로 "jquery"라는 패키지 이름만 보고 npm 패키지를 자동으로 찾아오지 않는다. 따라서 npm 패키지를 모듈로 사용하려면 Vite 같은 빌드 도구를 사용하거나, import map 같은 별도 설정이 필요하다.

3. CDN으로 jQuery 불러오기

CDN 방식은 별도의 설치 없이 HTML 문서에 jQuery 파일 주소를 연결하는 방식이다. 기초 예제나 간단한 정적 페이지에서 사용하기 쉽다.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>jQuery 기초</title>
</head>
<body>
  <h1 id="title">jQuery 시작하기</h1>

  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
  <script>
    $("#title").text("jQuery가 연결되었습니다.");
  </script>
</body>
</html>

jQuery 코드는 보통 HTML 요소가 모두 만들어진 뒤 실행해야 한다. 가장 단순한 방법은 script 태그를 body의 마지막 부분에 작성하는 것이다.

<body>
  <button id="btn">버튼</button>

  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
  <script>
    $("#btn").text("클릭 버튼");
  </script>
</body>

또 다른 방법은 $(function() { ... }) 문법을 사용하는 것이다. 이 문법은 DOM이 준비된 뒤 내부 코드를 실행한다.

$(function() {
  $("#btn").text("클릭 버튼");
});
$(function() { ... })는 “HTML 요소가 준비되면 이 코드를 실행하라”는 의미로 이해할 수 있다.

4. jQuery 기본 문법

4.1. 기본 형태

jQuery의 기본 문법은 다음과 같다.

$("선택자").기능();

예를 들어 아이디가 title인 요소의 글자를 변경하려면 다음과 같이 작성한다.

$("#title").text("제목이 변경되었습니다.");
구성 요소 의미 예시
$ jQuery 함수를 의미 $()
"선택자" 어떤 HTML 요소를 선택할지 지정 "#title"
.기능() 선택한 요소에 적용할 동작 .text()

4.2. JavaScript와 jQuery 비교

순수 JavaScript로 HTML 요소의 글자를 변경하는 코드는 다음과 같다.

document.querySelector("#title").textContent = "변경된 제목";

같은 작업을 jQuery로 작성하면 다음과 같다.

$("#title").text("변경된 제목");

jQuery는 선택과 조작을 짧게 작성할 수 있게 해 준다. 특히 여러 요소에 같은 작업을 적용할 때 코드가 간결해진다.

$(".item").text("같은 문구 적용");

5. 선택자

5.1. 기본 선택자

jQuery 선택자는 CSS 선택자와 비슷하다. 태그, 아이디, 클래스, 속성 등을 기준으로 HTML 요소를 선택할 수 있다.

선택자 의미 예시
$("p") 모든 <p> 요소 선택 $("p").hide()
$("#title") id="title" 요소 선택 $("#title").text("제목")
$(".box") class="box" 요소 선택 $(".box").css("color", "red")
$("*") 모든 요소 선택 $("*").css("font-size", "16px")
$("input") 모든 <input> 요소 선택 $("input").val() 
<h1 id="title">제목</h1>
<p class="desc">설명 문장입니다.</p>
<p class="desc">두 번째 설명입니다.</p>

<script>
  $("#title").text("jQuery 선택자");
  $(".desc").css("color", "blue");
</script>

5.2. 조합 선택자

여러 조건을 조합해서 선택할 수도 있다.

$("ul li").css("color", "green");
$(".menu .active").css("font-weight", "bold");
$("input[type='text']").css("border", "1px solid black");
선택자 의미
$("ul li") <ul> 안에 있는 모든 <li> 요소
$(".menu .active") menu 클래스 내부의 active 클래스 요소
$("input[type='text']") type="text"인 <input> 요소

5.3. 자주 사용하는 특수 선택자

$("li:first").css("color", "red");
$("li:last").css("color", "blue");
$("li:even").css("background-color", "#eee");
$("li:odd").css("background-color", "#ddd");
선택자 의미
:first첫 번째 요소
:last마지막 요소
:even짝수 인덱스 요소
:odd홀수 인덱스 요소

:even, :odd는 화면에서 보이는 순서의 1번째, 2번째가 아니라 JavaScript 인덱스 기준으로 동작한다. JavaScript 인덱스는 0부터 시작한다.

6. DOM 조작

DOM 조작은 HTML 요소의 내용, 속성, 스타일, 클래스를 변경하는 작업이다. jQuery는 DOM 조작을 위한 여러 메서드를 제공한다.

6.1. 텍스트 변경

$("#title").text("새로운 제목");

text()는 요소 안의 글자 내용을 변경하거나 가져올 때 사용한다.

<h1 id="title">기존 제목</h1>
<button id="btn">변경</button>

<script>
  $("#btn").on("click", function() {
    $("#title").text("버튼을 클릭했습니다.");
  });
</script>

6.2. HTML 내용 변경

$("#content").html("<strong>강조된 문장</strong>");

.html()은 선택한 요소의 HTML 내용을 가져오거나 설정하는 메서드이다.

<div id="content">기존 내용</div>

<script>
  $("#content").html("<strong>새로운 HTML 내용</strong>");
</script>

사용자가 입력한 값을 그대로 .html()에 넣으면 보안 문제가 생길 수 있다. 외부 입력값을 화면에 출력할 때는 가능하면 .text()를 사용하는 것이 안전하다.

// 권장
$("#result").text(userInput);

// 주의 필요
$("#result").html(userInput);

6.3. 입력값 가져오기

폼 요소의 값을 가져올 때는 .val()을 사용한다.

<input type="text" id="username">
<button id="checkBtn">확인</button>
<p id="result"></p>

<script>
  $("#checkBtn").on("click", function() {
    const name = $("#username").val();
    $("#result").text(name + "님, 환영합니다.");
  });
</script>

값을 직접 설정할 수도 있다.

$("#username").val("홍길동");

6.4. 속성 변경

HTML 속성을 가져오거나 변경할 때는 .attr()을 사용한다.

<img id="photo" src="before.jpg" alt="기존 이미지">
<button id="changeImg">이미지 변경</button>

<script>
  $("#changeImg").on("click", function() {
    $("#photo").attr("src", "after.jpg");
    $("#photo").attr("alt", "변경된 이미지");
  });
</script>

여러 속성을 한 번에 변경할 수도 있다.

$("#photo").attr({
  src: "after.jpg",
  alt: "변경된 이미지"
});

6.5. CSS 변경

CSS 속성을 변경할 때는 .css()를 사용한다.

$("#title").css("color", "red");
$("#title").css("font-size", "32px");

여러 스타일을 한 번에 적용할 수도 있다.

$("#title").css({
  color: "red",
  fontSize: "32px",
  backgroundColor: "yellow"
});

6.6. 클래스 추가와 제거

클래스를 다룰 때는 .addClass(), .removeClass(), .toggleClass()를 사용한다.

<style>
  .active {
    color: white;
    background-color: navy;
  }
</style>

<button id="btn">클래스 적용</button>
<p id="message">클래스 예제입니다.</p>

<script>
  $("#btn").on("click", function() {
    $("#message").addClass("active");
  });
</script>
메서드 의미
.addClass()클래스 추가
.removeClass()클래스 제거
.toggleClass()클래스가 없으면 추가, 있으면 제거
.hasClass()클래스가 있는지 확인
 
$("#message").addClass("active");
$("#message").removeClass("active");
$("#message").toggleClass("active");
$("#message").hasClass("active");

7. 이벤트 처리

7.1. 이벤트란?

이벤트는 사용자의 행동이나 브라우저에서 발생하는 특정 상황을 의미한다. 예를 들어 버튼 클릭, 키보드 입력, 마우스 이동, 폼 제출 등이 이벤트이다.

jQuery에서는 .on() 메서드를 사용해 이벤트를 연결한다.

$("선택자").on("이벤트이름", function() {
  실행할 코드
});

7.2. 클릭 이벤트

<button id="btn">클릭</button>
<p id="result"></p>

<script>
  $("#btn").on("click", function() {
    $("#result").text("버튼을 클릭했습니다.");
  });
</script>

7.3. 입력 이벤트

<input type="text" id="keyword">
<p id="preview"></p>

<script>
  $("#keyword").on("input", function() {
    const value = $(this).val();
    $("#preview").text(value);
  });
</script>

$(this)는 현재 이벤트가 발생한 요소를 의미한다. 위 코드에서는 사용자가 입력하고 있는 #keyword 요소를 가리킨다.

7.4. 폼 제출 이벤트

<form id="loginForm">
  <input type="text" id="userId" placeholder="아이디">
  <button type="submit">로그인</button>
</form>
<p id="message"></p>

<script>
  $("#loginForm").on("submit", function(event) {
    event.preventDefault();

    const userId = $("#userId").val();

    if (userId === "") {
      $("#message").text("아이디를 입력하세요.");
      return;
    }

    $("#message").text(userId + "님, 로그인 처리 중입니다.");
  });
</script>

event.preventDefault()는 브라우저의 기본 동작을 막는다. 폼의 기본 동작은 페이지 새로고침과 서버 전송이므로, JavaScript로 직접 검사를 하려면 기본 제출 동작을 막아야 한다.

7.5. 이벤트 위임

동적으로 추가되는 요소에는 일반적인 이벤트 연결이 동작하지 않을 수 있다. 이때 이벤트 위임을 사용한다.

<button id="addBtn">항목 추가</button>
<ul id="list">
  <li>기존 항목</li>
</ul>

<script>
  $("#addBtn").on("click", function() {
    $("#list").append("<li>새 항목</li>");
  });

  $("#list").on("click", "li", function() {
    $(this).remove();
  });
</script>

위 코드에서 #list는 처음부터 존재하는 요소이고, li는 나중에 추가될 수도 있는 요소이다. 따라서 #list에 이벤트를 걸고, 그 안에서 클릭된 li를 처리한다.

동적으로 추가되는 요소를 다룰 때는 이벤트 위임을 사용한다.

8. 요소 추가와 삭제

8.1. 요소 추가

jQuery에서는 HTML 요소를 쉽게 추가할 수 있다.

$("#list").append("<li>마지막에 추가</li>");
$("#list").prepend("<li>처음에 추가</li>");
메서드 의미
.append()선택한 요소의 내부 마지막에 추가
.prepend()선택한 요소의 내부 처음에 추가
.before()선택한 요소의 앞에 추가
.after()선택한 요소의 뒤에 추가
 
<button id="addBtn">추가</button>
<ul id="list"></ul>

<script>
  $("#addBtn").on("click", function() {
    $("#list").append("<li>새로운 항목</li>");
  });
</script>

8.2. 요소 삭제

선택한 요소 자체를 삭제할 때는 .remove()를 사용한다.

$("#target").remove();

선택한 요소는 남기고 내부 내용만 비우고 싶을 때는 .empty()를 사용한다.

$("#list").empty();
메서드 의미
.remove()선택한 요소 자체를 삭제
.empty()선택한 요소는 남기고 내부 내용만 삭제

9. 효과와 애니메이션

jQuery는 요소를 보이거나 숨기고, 간단한 애니메이션을 적용하는 메서드를 제공한다.

$("#box").hide();
$("#box").show();
$("#box").toggle();

예시는 다음과 같다.

<button id="hideBtn">숨기기</button>
<button id="showBtn">보이기</button>
<div id="box">박스입니다.</div>

<script>
  $("#hideBtn").on("click", function() {
    $("#box").hide();
  });

  $("#showBtn").on("click", function() {
    $("#box").show();
  });
</script>

시간을 지정할 수도 있다.

$("#box").hide(500);
$("#box").show(500);
$("#box").toggle(500);
메서드 의미
.hide()숨김
.show()표시
.toggle()보이면 숨기고, 숨겨져 있으면 표시
.fadeIn()서서히 나타남
.fadeOut()서서히 사라짐

10. 메서드 체이닝

jQuery는 여러 메서드를 이어서 호출할 수 있다. 이를 메서드 체이닝이라고 한다.

$("#title")
  .text("새 제목")
  .css("color", "red")
  .addClass("active");

위 코드는 #title 요소를 선택한 뒤, 텍스트 변경, CSS 변경, 클래스 추가를 순서대로 실행한다. 체이닝을 사용하면 코드를 간결하게 작성할 수 있다. 다만 너무 길게 이어 쓰면 가독성이 떨어질 수 있으므로, 여러 줄로 나누어 작성하는 것이 좋다.

11. Ajax 기초

11.1. Ajax란?

Ajax는 페이지 전체를 새로고침하지 않고 서버와 데이터를 주고받는 방식이다. 예를 들어 검색어 자동완성, 댓글 목록 불러오기, 좋아요 버튼 처리, 게시글 목록 추가 로딩 등에 사용할 수 있다.

11.2. GET 요청

GET 요청은 보통 데이터를 조회할 때 사용한다.

$.ajax({
  url: "/api/users",
  method: "GET",
  success: function(data) {
    console.log(data);
  },
  error: function() {
    console.log("요청 실패");
  }
});

간단한 GET 요청은 $.get()으로 작성할 수도 있다.

$.get("/api/users", function(data) {
  console.log(data);
});

11.3. POST 요청

POST 요청은 보통 데이터를 서버에 등록하거나 전송할 때 사용한다.

$.ajax({
  url: "/api/users",
  method: "POST",
  data: {
    name: "홍길동",
    age: 20
  },
  success: function(result) {
    console.log("등록 성공", result);
  },
  error: function() {
    console.log("등록 실패");
  }
});

간단한 POST 요청은 $.post()로 작성할 수도 있다.

$.post("/api/users", {
  name: "홍길동",
  age: 20
}, function(result) {
  console.log(result);
});

11.4. Ajax 사용 시 주의사항

Ajax는 아무 주소로나 요청을 보낼 수 있는 것이 아니다. 브라우저에는 동일 출처 정책이 있기 때문에, 다른 도메인으로 요청할 때는 서버에서 CORS 설정을 허용해야 한다.

또한 Ajax 요청은 서버가 있어야 정상적으로 테스트할 수 있다. HTML 파일을 더블 클릭해서 여는 방식보다는 로컬 서버나 백엔드 서버와 함께 실행하는 것이 좋다.

12. 종합 예제

다음 예제는 입력값을 받아 목록에 추가하고, 목록 항목을 클릭하면 완료 상태를 표시하며, 더블클릭하면 삭제하는 간단한 jQuery 예제이다.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>jQuery 종합 예제</title>
  <style>
    .done {
      color: gray;
      text-decoration: line-through;
    }

    li {
      cursor: pointer;
      margin: 6px 0;
    }
  </style>
</head>
<body>
  <h1>할 일 목록</h1>

  <input type="text" id="todoInput" placeholder="할 일을 입력하세요">
  <button id="addBtn">추가</button>

  <ul id="todoList"></ul>

  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
  <script>
    $(function() {
      $("#addBtn").on("click", function() {
        const todo = $("#todoInput").val();

        if (todo.trim() === "") {
          alert("할 일을 입력하세요.");
          return;
        }

        $("#todoList").append("<li>" + todo + "</li>");
        $("#todoInput").val("");
      });

      $("#todoList").on("click", "li", function() {
        $(this).toggleClass("done");
      });

      $("#todoList").on("dblclick", "li", function() {
        $(this).remove();
      });
    });
  </script>
</body>
</html>

문서 준비 후 실행$(function() { ... })DOM이 준비된 뒤 코드 실행
클릭 이벤트.on("click", function() { ... })버튼 클릭 처리
입력값 읽기.val()input 값 가져오기
요소 추가.append()목록에 새 항목 추가
클래스 토글.toggleClass()완료 상태 표시

13. jQuery 사용 시 주의할 점

jQuery는 편리하지만 모든 상황에서 반드시 필요한 것은 아니다. 최신 JavaScript는 querySelector, addEventListener, fetch, classList 같은 기능을 기본으로 제공하므로, 간단한 작업은 순수 JavaScript로도 충분히 처리할 수 있다.

하지만 기존 프로젝트가 jQuery로 작성되어 있다면 jQuery 문법을 이해해야 유지보수할 수 있다. 특히 관리자 페이지, 오래된 웹사이트, 템플릿 기반 프로젝트에서는 jQuery 코드가 자주 등장한다.

주의사항 설명
요소가 준비된 뒤 실행요소가 만들어지기 전에 선택하면 동작하지 않을 수 있다.
동적 요소에는 이벤트 위임 사용나중에 추가되는 요소는 부모 요소에 이벤트를 위임한다.
사용자 입력을 .html()에 직접 넣지 않기XSS 같은 보안 문제가 생길 수 있다.
하나의 프로젝트에서 버전 관리여러 jQuery 버전을 동시에 불러오지 않는다.
최신 프로젝트에서는 필요성 검토순수 JavaScript나 프레임워크로 해결 가능한지 판단한다.

jQuery 기초 문제 정답

문제1. jQuery는 JavaScript를 더 간단하게 작성할 수 있도록 도와주는 JavaScript 라이브러리이다. HTML 요소 선택, DOM 조작, 이벤트 처리, 애니메이션, Ajax 작업을 간단한 문법으로 처리할 수 있다.

문제2. CDN 방식은 HTML의 script 태그로 jQuery 파일 주소를 연결해 사용하는 방식이다. 모듈 방식은 npm으로 jQuery를 설치한 뒤 JavaScript 파일에서 import 문으로 jQuery를 가져와 사용하는 방식이다. 모듈 방식은 보통 Vite, Webpack 같은 빌드 도구 기반 프로젝트에서 사용한다.
